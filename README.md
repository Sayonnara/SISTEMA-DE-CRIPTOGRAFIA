# 🔐 Sistema de Criptografia

Aplicação web desenvolvida para demonstrar o funcionamento de técnicas de criptografia por meio de uma interface simples e interativa.

O projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, com o objetivo de aplicar conceitos de desenvolvimento web e lógica de programação na criação de um sistema de criptografia.

## 📌 Sobre o projeto

O **Sistema de Criptografia** permite ao usuário trabalhar com informações de forma codificada, utilizando os recursos implementados na aplicação.

A proposta do projeto é unir conceitos de:

* Desenvolvimento Web
* JavaScript
* Criptografia
* Lógica de programação
* Manipulação do DOM
* Interface de usuário

## 🚀 Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e layout
* **JavaScript** — lógica e funcionamento da aplicação

## 📂 Estrutura do projeto

```text
SISTEMA-DE-CRIPTOGRAFIA/
│
├── index.html
├── style.css
├── script.js
├── doc.text
└── README.md
```

### 📄 `index.html`

Responsável pela estrutura da página e pelos elementos da interface.

### 🎨 `style.css`

Responsável pela aparência da aplicação, incluindo layout, cores, espaçamentos e demais estilos.

### ⚙️ `script.js`

Contém a lógica responsável pelo funcionamento do sistema e pelas operações realizadas na aplicação.

### 📚 `doc.text`

Arquivo utilizado para armazenar a documentação/conteúdo relacionado ao projeto.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Sayonnara/SISTEMA-DE-CRIPTOGRAFIA.git
```

### 2. Entre na pasta

```bash
cd SISTEMA-DE-CRIPTOGRAFIA
```

### 3. Execute o projeto

Como a aplicação utiliza HTML, CSS e JavaScript, você pode abrir o arquivo:

```text
index.html
```

diretamente no navegador.

Também é possível utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.
